# Contributing to StudyLens / XYZ AI

Thank you for contributing to the StudyLens school ERP AI ecosystem.

## How to Contribute

1. Fork the repository.
2. Create a feature branch.
3. Keep changes focused and minimal.
4. Run local checks (`npm run lint`, build/dev sanity check).
5. Open a pull request with a clear summary.

## Pull Request Guidelines

- Describe the problem and the proposed solution.
- Reference related issue(s).
- Include screenshots/logs for UI or behavior changes where relevant.
- Update documentation for any user-facing change.

## Coding Guidelines

- Follow existing project structure and naming patterns.
- Avoid unrelated refactors in feature/fix PRs.
- Preserve role-based access and security guardrails when changing AI flows.

## Reporting Issues

When opening an issue, include:

- Expected behavior
- Actual behavior
- Reproduction steps
- Environment details (OS, browser, Node.js version)

## Security

Do not disclose vulnerabilities publicly. Report security concerns privately to repository maintainers.
